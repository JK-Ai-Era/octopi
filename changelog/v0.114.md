### feat(onboarding): 产品雏形批 1——init/agent 新建向导 CLI + 密码认证面

**旅程 A（安装→第一次对话）**：`octopi init` 升级为**首启体验器**——九步向导（欢迎语言 / 初始化方式 / 部署模式三选 / provider 预设 / API Key / 模型 / 测通 / 起服务 / 第一句话），CLI 先行（Web 向导批 2 打开）。预设复用 `BUILTIN_MODEL_PRESETS` 扩表（labels/keyHints 本地化）；key 落 `OCTOPI_HOME/.env`（0600）+ `${VAR}` 占位，配置面零明文；测通四类错误归并（auth/network/model/server）条条带出路；探针先展开 env 再建 provider。`--yes` 非交互路径（缺省 provider=ollama；②③模式经 `OCTOPI_ADMIN_PASSWORD`）。`octopi` 现有命令语义不变。

**部署模式三选（`deploymentMode` 配置）**：①personal = DEFAULT 域免登录（tenant/user id 显式 `default`，与 core `DEFAULT_TENANT_ID` 同 ID 空间）②organization = 单组织多用户 ③multi-organization = 多组织多租户（收组织名）。②③播种 admin + 密码（scrypt）；重跑同域幂等、异域撞名 fail-loud（`OCTOPI_ADMIN_NAME` 可改名）。

**密码认证面**：users 补 `password_hash/salt`、auth_tokens 补 `expires_at`（补列迁移）；`RegistryService` +setUserPassword/hasPassword/authenticate（(tenant?,name)+password，**等耗时 KDF** 防时序枚举）/createUserInTenant（事务）/ensureTenant(显式 id)/getUserInTenant。`/registry/login` 升级：**设密必验**、失败统一 401 `invalid_credentials`（防枚举）、免密名登录仅限 **loopback + 未设密用户**、失败 500ms 退避、token 统一 30 天 TTL。personal 远程绑定（host=lan/0.0.0.0）在向导内强制设密码。

**旅程 B（拥有自己的 agent）**：`octopi agent new` 四步（选类型 / 取名称呼 / 挂资料 / 试聊）。类型模板 = 生成器（Persona + skills 套装：AGENTS.md 主 persona + `persona/` 补充件 + `skills/<id>/SKILL.md` frontmatter）；registry agent 权威面（definition 白名单 + model 档位）+ bridge 物化 + 失败补偿回滚；通用 persona 脚手架清理（类型包是全量 persona）。chat 发现面合并 registry（config 优先、registry 回落）。挂资料 CLI 侧诚实降级为指引（两段式受管注册随批 2 webui 上传流）。

**配置面**：顶层 `language`（zh/en，CLI/agent 向导已消费）/`deploymentMode`；`loadOctopiEnvFile`（`loadConfig` 展开前灌 `OCTOPI_HOME/.env`，不覆盖已有键，进程树继承）；配置落盘前 schema 校验 fail-loud；模型档位三档 + default agent model 全部接线到所选 provider/model。
