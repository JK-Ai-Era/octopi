## v0.122.0 (2026-11-22)


### feat(skills): 内置文档设计编写技能家族随包发布并种子落盘（document-authoring + docx/pdf/pptx/xlsx）

- **内容**：新增仓库 `skills/`（随 npm 包发布，`files` 增列 `skills`）。`document-authoring` 共享底座（设计教义 design.md、QA 协议 qa.md、单份 OOXML 工具链 `scripts/office/`（ISO-29500 XSD 校验 / unpack / pack / soffice 封装）+ PDF→PNG 渲染脚本）+ `docx`/`pdf`/`pptx`/`xlsx` 四格式 SKILL.md（编写工作流与格式坑位）。为移植四套 skill 的重构版：保留库坑位知识与机制化校验闭环，读路径统一改原生 `document_read`/`document_probe`（对齐 `arch/document-port.md` 分工表），设计教义从 pptx 升格为四格式共享层，QA 统一「渲染→异眼复核→修复→再验证」协议。
- **机制**：`ensureAgentDirs` 新增 `seedBuiltinSkills` —— 随包 `skills/` copy-if-missing 种子进 `agents/<id>/skills/`（用户数据优先，与 persona 四件套同语义）；`findBuiltinSkillsDir` 自模块位置向上解析包根（不绑死构建布局）；种子缺失/复制中断显式 warn 降级不阻塞初始化。既有文件绝不覆盖；后续版本**新增**文件会下次脚手架补种（技能树可能跨版本混放），完整升级需显式重装。
- **去重与本地化**（`arch/document-port.md` skills 瘦身 P2 收口）：`scripts/office/` 三份拷贝（约 3.4MB）收敛为单份、格式 skill 跨目录引用；默认批注作者 Claude→Assistant；工具名对齐 `file_edit`/`delegate_dispatch`；Python 脚本收敛 3.9 兼容（`match`→`if/elif`、future annotations）；PDF→JPEG 渲染（共享渲染脚本与 pptx 缩略图）改 pypdfium2，去 pdf2image/poppler **硬**依赖（`pdfimages` 保留为标注可选项）。
- **依赖显式化**：SKILL.md 增依赖矩阵（各能力硬依赖 + 降级路径）；缺依赖显式报「此路径不可用」并给替代，禁止静默降级。
