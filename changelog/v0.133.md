## v0.133.0 (2026-11-27)

### feat(engine,gateway,webui): effectPolicy 合并改「逐键兜底」（2026-11-26 拍板）

对象级覆盖（`agent.effectPolicy ?? config.effectPolicy` 整段赢）改为**逐键兜底**：
agent 写了的键赢、没写的键跟全局缺省。这是合并语义架构变更（Y 位）。

- **引擎**：新增 `mergeEffectPolicy(host, agent)` 统一合并（唯一真相源），四个装配点
  全部收口——`run-assembly` / `config-bridge` / `builder`（显式 vs runnerConfig 缺省）/
  gateway 会话根解析。嵌套对象整值替换、`undefined` 视为未写。
- **两把路径清单键并集**（唯一例外，各取安全/直觉方向）：`transactionRoots` 追加授权
  （宿主根 + agent 自带根并集，「跟随全局 + 自带目录」可表达，加目录不再静默丢宿主根）；
  `pathDenylist` 拒绝只收紧（agent 级清单不能放松宿主拒绝）。已知 give-up：agent 不能
  比宿主更窄（要收窄用 `pathDenylist` 或别把宽根放全局）。
- **写入协议**：`updateAgent` 二级合并补「子键 null = 删键」（`effectPolicy: { mode: null }`
  = 该键改回跟随全局，其余子键——含隐藏旋钮——不动）；合并后空对象自动收干净。
  「继承全局」由此从「删整段」降为「删 mode 键」，结构性修复评审 F7（不再误删
  面板未展示的安全旋钮）。
- **WebUI 大幅简化**（上一版为绕对象级坑加的防护全部移除）：不再固化安全组、无确认
  弹窗、无「继承全局 × 工作目录」互斥拦截（该组合现在可表达：`{ mode: null, transactionRoots }`）；
  安全组表单按 `effectModeSource` 诚实显示（跟随全局时不虚标为 agent 级选择）；
  工作目录区展示全局根（「来自全局」只读行），并集可见。
- **测试**：新增 `effect-policy-merge.test.ts`（合并助手单元锚，含 standalone / 嵌套整组
  重写 give-up 锚）；config-apply +2（#6b 子键 null 删键、#6c 删空收干净）；config-bridge
  契约改逐键断言 + 1 例「写 transactionRoots 不丢全局 mode」根因锚；AgentSettingsPanel
  逐键断言（含 F-d 可共存锚、F3/F7 无弹窗锚）。
- **二轮独立评审修复（F-1~F-10 处理）**：
  - **F-1 租户隔离补口**（major）：registry 派生的租户 agent 现标记 `effectPolicyStandalone`
    （宿主派生、config/definition 无法伪造），四个合并点全程「自成一套」——平台顶层的
    `pathContainment`/`toolIsolation`/`shellEscape`/`transactionRoots`/`pathDenylist` 等
    旋钮不再泄漏给租户 agent（此前逐键兜底会把 host 旋钮漏给恒 workspace 姿态的租户）。
  - **F-2 提权闸改按生效模式判据**（major，**用户可见行为变更**）：不再按请求体字面量判。
    create 不带 `effectPolicy.mode` 且全局缺省为 host 时**现在拒 503**（此前会静默造出
    host 全权 agent）；`mode: null` / `effectPolicy: null` 回落全局 host 同罪拒。显式写
    `mode: workspace|project|untrusted` 或降权不受影响。
  - **F-3 读写面补集纳入闸与指纹**（major，**用户可见行为变更**）：无认证写入
    `effectPolicy.pathDenylist` / `refuseFinalSymlink`（含 `null` 删键、清空、替换）现在
    **拒 503**（deny 清单是读写面的拒绝侧，方向不可静态判定）；两键同时纳入
    `EFFECT_POLICY_SECURITY_KEYS`（此前删键 reattest 记 `changed: []`，安全放松审计不可见）。
  - F-4/F-8 文档锚：嵌套旋钮必须整组重写（已知 give-up）+ `mergeEffectPolicy` 单侧
    返回入参引用的调用契约已注释。
  - F-5 清空工作目录改发 `transactionRoots: null`（删键回全局，不再留空壳）。
  - F-6 `getAgentsView` 透出 `globalEffectMode`，「继承全局」卡片显示当前全局安全组
    （global=host 时点它是提权，不再静默）。
  - F-7 三处「整体覆盖」注释改逐键兜底表述。
  - F-9 `addWorkdir` 查全局根防重复行。
- **验证**：全量 `npm test` 6107 用例通过（9 skipped，590 文件）；`npm run lint` 通过；`arch/check-sync.sh` 绿。
- **文档**：`arch/tool-effect-policy.md` 拍板表补合并语义。
