## v0.72.2 (2026-10-12)

### feat(memory): surface recall timestamps and as-of freshness

**问题**：memory 召回几乎不带时间——MemoryLayer 注入只有 `- [type] content`，`memory_search` 返回裸 epoch `createdAt`。时效敏感 fact（环境、版本、约定）被当成现状采信，导致误判。且只有入库时刻 `createdAt`，没有「命题当时成立」的 as-of 语义。

**调整**：
- **P0 召回带时间**：MemoryLayer 每条后缀 `· recorded YYYY-MM-DD HH:mm`（本地墙上时钟，与 Runtime `Current datetime` 对齐）；`memory_search` 返回可读 `recordedAt` / `asOf`，工具描述要求对照当前时间判时效
- **P1 asOf**：`memory_store` 可选 `as_of`（`YYYY-MM-DD` / epoch）；非法值 `invalid_as_of` 且不写库。`MemoryEntry` / `MemoryWriteSlot` 增 `asOf`；`agent.db` 补 `as_of` 列（旧库 ALTER 迁移）
- **产品宪法** Memory 段：时效敏感 fact 须对照 `Current datetime`，过时用 `supersedes_id` 纠正
- `docs/memory.md`：区分 recorded（入库）与 as of（成立）

**测试**：`tests/memory/memory-recall-time.test.ts`（格式化/解析、store+search 时间字段、非法 as_of 拒写、MemoryLayer 注入、Sqlite 往返）；memory 相关套件 181 过。

## v0.72.1 (2026-10-12)

### docs(session): sync comments and contracts after lease/branch/edit-resend

**问题**：v0.72.0 改了会话连续性模型后，Runner 文件头、backfill 注释、`arch/*` 仍写「daily/idle reset 会清空 messages / `markSessionRecent`」，后续开发会按旧模型改代码。

**调整**：
- Runner 头注释与 Assembler 钩子注释改为「上下文租约 / 中止编辑重发」语义
- `backfill-trigger` 注释去掉「reset 清空 messages」
- `arch/session-history-search.md` 状态表：结束/`/new` 硬收敛 → `recent`；去掉 `markSessionRecent`
- `arch/session-agent-run.md` 验收项改为上下文租约 + abort/edit-resend
- `docs/CONTRIBUTING.md` 补 SessionStore 契约：`save` 浅合并 metadata、删键必须 `updateMetadata`、`contextDetachIndex` 随 messages 重写同步、truncate 须持 sessionLease

**测试**：`arch/check-sync.sh` 通过；无行为变更。

## v0.72.0 (2026-10-12)

### feat(session): context lease, copy-prefix branch, and abort edit-resend

**问题**：从历史会话继续对话时像「新会话」——Runner 的 daily/idle reset 会清空 `session.messages` 与 compact；同时缺少从任意用户节点分叉、以及中止后原地纠错的能力。

**调整**：
- **上下文租约（opt-in）**：删除破坏性 `enableDailyReset` / 消息清空；`session.idleExpiryMs` 显式配置才生效，闲置超时仅写 `contextDetachIndex` 截断 LLM 默认窗口（Discourse 全量保留，可 `session_search` / `session_read`）。与 memory 冷沉淀解耦；超窗继续走 compact；新开会话用 `/new`
- **Session 分叉（copy-prefix）**：`POST /sessions/:id/branch`（`beforeIndex`）复制 `[0, beforeIndex)` 到新会话并播种 compact；`getSessionMessages` 附带绝对 `index`；用户气泡「分叉」（首条用户气泡不提供）
- **中止后编辑重发（同会话，不建分支）**：Runner 仅在本轮未完成被掐断时打 `abortedTurn`；`POST /sessions/:id/messages/truncate` + store `editAndResend` 原地截断残片后重发；`abortedTurn` 删键走 `updateMetadata`（save 浅合并删不掉）
- **一致性**：`contextDetachIndex` 随 messages 重写/截断同步；truncate 持 `sessionLease` 与 runner 写回串行；`editResendable` 不进 conversation cache，正常收尾清除入口
- **UI**：编辑态气泡加宽；侧栏会话卡片长标题截断不溢出

**测试**：`context-lease`（默认全量 / 截窗保留 Discourse / 不触发 memory）、`session-branch`（前缀切割 / 越界 / index）、`session-edit-resend`（truncate + 删键 + detach 钳制 + 过期标记）通过。
