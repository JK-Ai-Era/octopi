## v0.80.0 (2026-10-16)

### feat(tools): dedicated git/package tools for workspace without shell

**问题**：`workspace`（`shellEscape=deny`）与 `untrusted` 降级面禁止 shell，agent 无法做 git / npm 类必要操作，编码闭环断裂。

**拍板**：专用工具替代 shell——git 走 spawn argv allowlist（方案 A）；`project_run` 标 `runner`（reduced 面剥离）；`package_install` 标 `egress`（网络开才可用，否则提示手动 install）。

**新增工具面**（builtin，开箱即用，无需 allowlist 配置）：

| 工具 | 能力 | reduced 面 |
|------|------|------------|
| `git_status` / `git_diff` / `git_log` / `git_show` | `vcs` | 放行 |
| `git_commit` / `git_branch` / `git_restore` | `vcs` | 放行 |
| `package_edit` | `fs-write` | 放行 |
| `project_run` | `runner` | **剥离** |
| `package_install` | `egress`+`runner` | **剥离** |

**能力标签**：`ToolCapability` 增 `vcs` / `runner`；`REDUCED_DENIED` 增 `runner`（不增 `vcs`）；`shellEscape` 只闸 `kind:'shell'`，不拦 `vcs`/`runner`。

**安全加固（双轮审查后）**：

- Windows 不 spawn `.cmd`/`.bat`（CVE-2024-27980 `EINVAL`）：`resolveNodeToolCommand` → `node <npm-cli.js>`；`findExecutable` PATHEXT（`.exe`）优先。
- git 隔离：不存在的 `core.hooksPath`、`--no-verify`/`--no-gpg-sign`/`--no-ext-diff`、`-c` 覆盖 `diff.external`/`gpg.program`/`core.sshCommand`/`core.pager`、`GIT_CONFIG_GLOBAL/SYSTEM`→`NUL`/`/dev/null`、`filter.*` 发现后钉 `cat`。
- `forceEnvKeys` 强制放行 `GIT_*`/`npm_config_*`（否则 `scrubEnv` 静默剥掉）；`defaultChildEnv` 补 `SystemRoot`/`TEMP`/`HOME`。
- `package_edit` 禁原型污染键；保留 CRLF/LF、缩进、尾换行。
- pathspec：简单路径仍 L2；glob 保持相对，禁 `..`/绝对/NUL。
- cwd 过 attachment/undo 守卫；`npm_config_cache` 指 tmpdir（jail 无 homeWrite 可用）。
- `package_install` 在 `networkPolicy≠open` 时拒绝并提示手动 install。

**文档**：`docs/process-isolation.md|.zh.md`（vcs/runner 剥离面 + 隔离手段）、`default-agents.md`（git/package 专用工具优先）。

**测试**：`tests/harness/dedicated-tools.test.ts`（能力/gateEffect/原型污染/EOL/pathspec）+ `dedicated-tools-functional.test.ts`（真 git 仓库、恶意 filter 不执行）；`builtin-tools`/`extension-tools` 计数 24。
