## v0.132.6 (2026-11-25)

### feat(engine): skill consumption S3 — skill_read activation semantics (session-scoped body, aged listings)

技能激活/老化语义 S3（`arch/skill-creation-design.md` §12.3）：技能正文是「会话级知识」而非「临时查文件」，与 `file_read` 的 `[aged]` 行为刻意不同。

- **激活语义**：`skill_read` 不带 `file` 的调用 = 激活——正文永不老化（会话内常驻，可重复引用不需重读）；清单超过 24K 字符体量时降级为纯文件名列表（`skill_list` 可重列）。带 `file` 的调用 = 查阅——老化为可重读指针（`skill_read(id, file=…)` 一键重取）。
- **实现**：`ageResult` 声明（RegisteredTool 既有 per-tool 老化契约，纯函数——体量分档确定性，无时钟/状态依赖）+ 激活分支返回 `activation` 预算标注（bodyChars/approxTokens——正文体量大时模型可自行取舍后续激活）。
- 测试锁：ager 纯函数性（同输入恒同字节）、大小体量分档、file= 指针形态、activation 标注。

## v0.132.5 (2026-11-25)

### feat(engine): skill consumption S2 — skill_list/skill_search with shared search-matchers

技能检索面 S2（`arch/skill-creation-design.md` §12.3）：多文件技能的清单与内容搜索。

- **`skill_list(id, subdir?, pattern?)`**：附件清单面（路径/大小/类型，不带内容）；`subdir` 前缀 + 路径 glob 过滤（清单超限时的收窄续路）。
- **`skill_search(id, pattern, patterns?, glob?, …)`**：技能目录内内容搜索。在 consume 快照字节上扫描（搜到的即通过审查锚定的内容；漂移包拒搜）；**SKILL.md 搜索坐标 = skill_read 正文坐标**（stripFrontmatter 单源，命中可直接 offset 续读不偏移）；输出预算（单行 300 字符 + 128KB 总预算剥上下文）；`truncated` 精确（恰好满额不误报）+ `filesSkippedBinary` 计数。
- **`search-matchers.ts` 共享单源**：`compileContentMatchers`/`lineMatches`/`collectPatternTerms` 从 `file-search.ts` 平移为共享导出——`file_search` 与 `skill_search` 同一 pattern 语义（auto 判定/`a|b` 字面 OR/空白词条过滤），不再两处漂移。
- **消费面拒绝语义统一**：skill_list 对 drift/停用/未过审 throw（与 skill_read/skill_search 一致），仅 unreadable 柔性标注。
- **独立评审 2 Major + 2 Medium 全修复**（上下文预算收缩、SKILL.md 坐标分裂、清单面拒绝降级、词条收集漂移）+ Low 清单（死代码/魔数/二进制阈值收敛、测试缺口补齐）。



## v0.132.4 (2026-11-25)

### feat(engine): skill consumption S1 — skill_read/skill_run with single-IO review-anchored reads

技能消费面 S1（`arch/skill-creation-design.md` §12）：技能正文/附件/脚本的按需读取与执行不再依赖通用 `file_read`（strict 非 host 档读不到 `~/.octopi/skills/**` 的缺口），改为 `skill_*` 专属命名空间（拍板 §12.7-1）。

- **`skill_read(id, file?, offset?, limit?)`**：不给 `file` 返回 SKILL.md 正文 + 附件清单（首行提要）一次给出；给 `file` 分段读附件。大小三层防线：读取侧截断 + 续读指针、清单条目/提要上限、`limit` 参数硬顶（5000 行，防超大参数绕过截断）。
- **`skill_run(id, script, args?, timeout?)`**：技能脚本执行面（§12.4）。解释器三级解析（shebang → `metadata.interpreter` → 扩展名映射；`.bat`/`.cmd` 拒执行，CVE-2024-27980）；执行副本机制（执行字节 = 通过审查锚定的字节）；jail 只读根 = 技能目录（bwrap `--ro-bind-try` + Seatbelt 后置 deny 双后端强制）、写根 = workspace（产出入 shell journal 账本）；`gateEffect kind:'runner'`（不受 shellEscape 闸，host-gate 仍确认）+ `ops.command.executed` 审计（含 unreviewed/jail 标注）。
- **`SkillManager.load()` 消费面单源升级**：`consume()` 单 IO 快照——读到的字节与内容哈希同源，闭合「锚定算 A、消费读 B」TOCTOU；`/name` 命令展开与工具读取同锚（审查哈希锚定，漂移即拒）；拒绝态细分（`hash_drift`/`disabled`/`not_approved`/`unreadable`——停用不再误报「被篡改」）；SKILL.md symlink 不入索引（F26）。
- **sandbox `readonlyRoots` 原语**：只读挂载根（bwrap `--ro-bind-try` 词法+canonical 双形；Seatbelt 后置 deny 压掉父路径 allow）。
- **validate 新规则**：`scripts/` 二进制禁令（可审计文本源码——审查机制内在要求；Windows 分隔符归一）+ SKILL.md 200KB 硬限（软限沿用 `body_too_long`）。
- **消费面工具注册不绑 lifecycle**：嵌入式/无 skill-state 部署同样有 `skill_read`/`skill_run`（F10）。
- **独立评审 28 findings 全裁定**（1 blocker 计划内 + 10 major 修复：TOCTOU 快照闭合、锚定异常 fail-closed、读取字节闸、`.bat/.cmd` 注入面拒、Seatbelt 只读、journal 入账、注册拆分、interpreter 分词（`env -S`）等；F7②「shellEscape 旁路」为拍板 §12.7-1 设计意图不修；F28 hardlink 有意不做）。

### feat(engine,gateway,cli): skill-creator P1 — 技能自创建的提交、审查与启用闸门

技能自创建能力首期（设计定稿见 `arch/skill-creation-design.md`，2026-11-25 四项拍板收口）：

- **规范对齐（agentskills.io）**：`skills/frontmatter.ts` 解析单源化（`allowed-tools` 标准字段、兼容旧 `tools`/顶层扩展键、metadata 单层嵌套、command 归一；块标量等认不出的形态显式 `unsupported`，不再静默当值收下）；`skills/validate.ts` 校验器（name/description MUST→error、危险模式扫描→warning 审查线索、symlink/大小安全阀）。
- **启用闸门（唯一真相源）**：`skills/registry.ts`（skill-state/skills.db，sqlite WAL——审查与 discover 自动登记是真实并发写方）+ `skills/lifecycle.ts`（提交/审查/启停/准入的单一实现）。语义按拍板：`skill_submit` 来源须过审；host 直写/用户拷贝按**放盘即信任**自动登记（`dropped-in` + unreviewed 标注，不拦截）；submitted 哈希漂移 = 审查作废回 pending（**审查的是内容不是名字**）。
- **工具面**：`skill_submit`（沙箱起草 → 引擎 staging → 审查单；校验失败逐项错误 fail-loud）+ `skill_status`（审查进度/驳回 findings；对外 DTO 不泄内部路径）。
- **人工审查面**：`octopi skill list|show|approve|reject|enable|disable`（show = staging 内容预览）+ REST `GET /skills`、`GET /skills/submissions/:id`、`POST /skills/review`、`POST /skills/enable`。署名取认证身份（B-1 拍板同规，不信客户端自报）；review/enable 在无认证部署 503 拒写（防 agent 自批），disable 止血放行。
- **独立评审修复（P0/P1）**：闸门异常不中止 discover、不失闸（per-item fail-closed + 兜底 manager 继承 gate）；同名提交不可顶下线已批准技能/抹审查记录；批准物化做 staging 哈希锚点校验（漂移即要求重提，不再拿旧 staging 覆盖磁盘新版本）；staging 复制后二次校验（TOCTOU 收口）；skill-state 目录 owner-only。
