# @octopi-agent/webui

Octopi **Web UI** — prebuilt console (static assets). Installed as a dependency of `octopi-agent` and served by `octopi webui start`.

```sh
npm i @octopi-agent/webui
```

This package ships **`dist/`** only (no Vite source). Development lives in the [octopi monorepo](https://github.com/JK-Ai-Era/octopi) under `packages/webui`.
